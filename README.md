# DexterPCB
Contains all files needed to create/modify the Dexter custom PCB.

Dexter is a hardware replacement for laserdisc players used in arcade games such as Dragon's Lair.

Dexter is a two board solution: a larger custom PCB that sits on the bottom and a smaller Raspberry Pi v2 the sits on the top.  This repo contains the Eagle files and Bill of Materials spreadsheet to create/modify the custom PCB that sits on the bottom.

The Dexter custom PCB contains two microcontrollers.  The source code for these microcontroller is at https://github.com/RulecityLLC/DexterFirmware .

# PCB
I created this PCB with Eagle v6.  It should work with KiCad's EAGLE importer though I have not tested it.

# Bill of Materials
I included the actual spreadsheet I use when ordering parts for this PCB and assembling this PCB.
